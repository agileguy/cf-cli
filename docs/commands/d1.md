# `cf d1` — Serverless D1 SQL Database Management

Manage Cloudflare D1 distributed SQLite-based serverless SQL databases, execute queries, run batch migrations, and import/export SQL dumps.

---

## Required Permissions

| Action | Scope Level | Minimum API Token Permission |
|--------|-------------|------------------------------|
| Read   | Account     | `D1:Read`                    |
| Write  | Account     | `D1:Edit`                    |

---

## Subcommands Overview

- [`cf d1 list`](#cf-d1-list) — List all D1 databases in your account
- [`cf d1 get`](#cf-d1-get) — Inspect database metadata, UUID, and table counts
- [`cf d1 create`](#cf-d1-create) — Provision a new serverless database
- [`cf d1 delete`](#cf-d1-delete) — Delete a database
- [`cf d1 query`](#cf-d1-query) — Execute SQL statements (SELECT, INSERT, UPDATE)
- [`cf d1 export`](#cf-d1-export) — Export database schema and table rows as SQL dump
- [`cf d1 import`](#cf-d1-import) — Execute SQL commands from a `.sql` file

---

### `cf d1 list`

Lists all D1 databases in your account.

#### Syntax
```bash
cf d1 list [--name <filter>] [--page <num>] [--per-page <num>]
```

#### Example
```bash
cf d1 list
```

---

### `cf d1 create`

Provisions a new serverless D1 database.

#### Syntax
```bash
cf d1 create --name <database-name> [--location-hint <region>]
```

#### Example
```bash
cf d1 create --name production-db
```

---

### `cf d1 query` / `cf d1 execute`

Executes SQL statements directly against your D1 database with parameterized query support.

#### Syntax
```bash
cf d1 query "<sql-statement>" --database <name-or-id> [flags]
```

#### Flags
| Flag | Type | Description |
|------|------|-------------|
| `--database <name-or-id>`| string | *required* Database name or UUID |
| `--sql <statement>` | string | Alternative to positional SQL argument |
| `--params <json-array>` | string | JSON array of bind parameters for prepared statements |
| `--output <format>` | string | `json` or `csv`; anything else, including `yaml`, falls back to the table. This is currently the only command that acts on `--output` |

#### Examples
```bash
# Query table and format as an ASCII table
cf d1 query "SELECT id, email, created_at FROM users LIMIT 10;" --database production-db

# Run parameterized INSERT
cf d1 query "INSERT INTO users (email, role) VALUES (?, ?);" --database production-db --params '["dev@example.com", "admin"]'

# Extract query results directly as JSON
cf d1 query "SELECT * FROM orders WHERE status='pending';" --database production-db --output json | jq '.'
```

---

### `cf d1 export` & `cf d1 import`

Perform database backups, migrations, and seed scripts.

```bash
# Export full database schema and data to SQL dump file
cf d1 export --database production-db --output-file backup.sql

# Import and execute SQL statements from a file
cf d1 import --database production-db --file schema.sql
```

---

### `cf d1 delete`

Destroys a D1 database and all stored data.

#### Syntax
```bash
cf d1 delete --database <name-or-id> [--yes]
```

#### Example
```bash
cf d1 delete --database test-db --yes
```
