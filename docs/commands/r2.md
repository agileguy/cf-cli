# `cf r2` — R2 Object Storage Management

Manage Cloudflare R2 S3-compatible zero-egress fee object storage buckets, custom domain bindings, lifecycle rules, CORS configurations, and event notifications.

---

## Required Permissions

| Action | Scope Level | Minimum API Token Permission |
|--------|-------------|------------------------------|
| Read   | Account     | `Workers R2 Storage:Read`    |
| Write  | Account     | `Workers R2 Storage:Edit`    |

---

## Subcommands Overview

- [`cf r2 buckets`](#cf-r2-buckets) — Create, list, inspect, and delete R2 buckets
- [`cf r2 cors`](#cf-r2-cors) — Configure Cross-Origin Resource Sharing (CORS)
- [`cf r2 lifecycle`](#cf-r2-lifecycle) — Configure automatic object expiration and transitions
- [`cf r2 custom-domains`](#cf-r2-custom-domains) — Map public custom domains to buckets
- [`cf r2 event-notifications`](#cf-r2-event-notifications) — Send bucket mutation events to Cloudflare Queues
- [`cf r2 metrics`](#cf-r2-metrics) — Inspect bucket storage usage and operation counters

---

### `cf r2 buckets`

Manage R2 storage buckets.

```bash
# List all buckets in account
cf r2 buckets list

# Inspect bucket metadata and location hint
cf r2 buckets get --name my-assets

# Create a new bucket with optional jurisdiction/location hint
cf r2 buckets create --name my-assets [--location wnam]

# Delete an empty bucket
cf r2 buckets delete --name my-assets [--yes]
```

---

### `cf r2 cors`

Manage HTTP CORS policies allowing browser clients to perform direct uploads/downloads.

```bash
# View active CORS rules for a bucket
cf r2 cors get --bucket my-assets

# Apply CORS configuration from a JSON policy file
cf r2 cors set --bucket my-assets --file cors-policy.json

# Remove all CORS rules
cf r2 cors delete --bucket my-assets [--yes]
```

*Example `cors-policy.json`:*
```json
[
  {
    "allowed": {
      "origins": ["https://example.com"],
      "methods": ["GET", "PUT"],
      "headers": ["*"]
    },
    "maxAgeSeconds": 3600
  }
]
```

### `cf r2 lifecycle`

Automate object cleanup and retention by configuring lifecycle rules.

```bash
# View active lifecycle rules
cf r2 lifecycle get --bucket my-assets

# Apply lifecycle rules from a configuration file
cf r2 lifecycle set --bucket my-assets --file lifecycle.json
```

*Example `lifecycle.json` (auto-delete objects after 30 days):*
```json
{
  "rules": [
    {
      "id": "expire-temporary-uploads",
      "enabled": true,
      "conditions": {
        "prefix": "temp/"
      },
      "action": {
        "type": "Delete",
        "maxAge": 2592000
      }
    }
  ]
}
```

### `cf r2 custom-domains`

Expose an R2 bucket directly to public HTTP traffic through a custom domain on your Cloudflare zone.

```bash
# List custom domains mapped to a bucket
cf r2 custom-domains list --bucket my-assets

# Bind a custom domain (e.g. cdn.example.com) to a bucket
cf r2 custom-domains add --bucket my-assets --zone example.com --domain cdn.example.com

# Remove custom domain binding
cf r2 custom-domains remove --bucket my-assets --domain cdn.example.com [--yes]
```

---

### `cf r2 event-notifications`

Emit notifications to Cloudflare Queues whenever objects are uploaded, copied, or deleted.

```bash
# List notification rules
cf r2 event-notifications list --bucket my-assets

# Create notification triggering on PutObject
cf r2 event-notifications create --bucket my-assets --queue image-pipeline --rules '[{"actions":["PutObject"]}]'

# Delete notification rule
cf r2 event-notifications delete --bucket my-assets --queue image-pipeline [--yes]
```

---

### `cf r2 metrics`

Inspect bucket storage volume, object counts, and operation metrics.

```bash
cf r2 metrics --bucket my-assets
```
